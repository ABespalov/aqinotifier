# Документация системы локализации AQI Notifier (v2.2)

Система локализации бота AQI Notifier построена на базе **рекурсивного блочного шаблонизатора** с поддержкой логики на стороне шаблонов. Это позволяет полностью отделить логику отображения (иконки, тексты, структуру сообщений) от программного кода.

---

## 1. Базовый синтаксис

### 1.1. Плейсхолдеры
Основной формат: `@key%format@`
- `key`: Имя ключа в JSON или имя переменной, переданной из Go.
- `format`: Опциональный модификатор (форматирование чисел, дат или регистра).

### 1.2. Рекурсивное разрешение
Если значение ключа содержит другие плейсхолдеры, они будут разрешены рекурсивно.
**Пример:**
`"txtDevice": "@icoDevice@ @deviceName@"`
Шаблонизатор сначала найдет `icoDevice` в словаре, затем подставит переменную `deviceName`.

---

## 2. Условные конструкции (Логика)

Синтаксис: `@?condition%true_text%false_text@`

### 2.1. Операторы сравнения
| Оператор | Алиасы | Описание |
| :--- | :--- | :--- |
| `==` | `eq` | Равно |
| `!=` | `ne` | Не равно |
| `>` | `gt` | Больше |
| `<` | `lt` | Меньше |
| `>=` | `ge` | Больше или равно |
| `<=` | `le` | Меньше или равно |
| `isEmpty` | - | Истина, если значение пустое или 0 |
| `isNotEmpty` | - | Истина, если значение не пустое |

### 2.2. Вложенные условия (Switch)
Если `false_text` начинается с `?`, он обрабатывается как следующий уровень условия.
**Пример:**
`"txtHeader": "@?isAlert%ВНИМАНИЕ%?isNorma%НОРМА%ИНФО@@"`
*(Если isAlert=true -> ВНИМАНИЕ, иначе если isNorma=true -> НОРМА, иначе ИНФО)*

---

## 3. Модификаторы форматирования

### 3.1. Регистр (Case Formatters)
- `%toUpper`: ПЕРЕВОДИТ В ВЕРХНИЙ РЕГИСТР
- `%toLower`: переводит в нижний регистр
- `%toTitle`: Делает Первую Букву Заглавной

### 3.2. Числа (printf)
Используется синтаксис Go:
- `%.1f`: 12.3
- `%.2f`: 12.34
- `%d`: 123

### 3.3. Дата и время
- `%02.01.2006`: 02.05.2024
- `%15:04:05`: 14:30:05

## 4. Справочник плейсхолдеров (Go -> JSON)

Ниже перечислены основные ключи, вызываемые из кода, и переменные, которые им доступны.

### 4.1. `msgStatus` и `msgAlertNotify`
Эти шаблоны получают полный набор данных о состоянии датчиков.

**Переменные данных:**
- `@date@`, `@time@`: Объект времени (требует формат).
- `@deviceId@`, `@deviceName@`: ID и имя устройства.
- `@aqiVal@`: Численное значение AQI.
- `@aqiLevel@`: Уровень (1-7). Используется для сборки иконки: `@icoLevel@aqiLevel@@`.
- `@aqiName@`: Локализованное название уровня.
- `@aqiStandardFlag@`: Ссылка на флаг стандарта (`@flagUs@`/`@flagEu@`).
- `@val25@`, `@val10@`: Текущие значения PM.
- `@diff25Percent@`, `@diff10Percent@`: Изменение в %.
- `@trend25Icon@`, `@trend10Icon@`: Иконки тренда (стрелки).
- `@zone25Icon@`, `@zone10Icon@`: Иконки текущей зоны (квадраты).
- `@valT@`, `@valH@`, `@valP@`, `@valDp@`: Метеоданные.

**Переменные состояний (только для `msgAlertNotify`):**
- `@isAlert@`: `true`, если зафиксировано ухудшение.
- `@isNorma@`: `true`, если качество воздуха вернулось в норму.
- `@evt<EventName>@`: Флаги конкретных событий (например, `@evtVal10Yu@`, `@evtPm25Rise@`). Используются в `txtAlertsList`.

### 4.2. `msgHelp`
- `@bot_version@`: Текущая версия бота.

### 4.3. `msgAqiCycleMenu` (Настройка границ)
- `@vg1@`, `@vy1@`: Границы Зеленой и Желтой зон для PM2.5.
- `@vg2@`, `@vy2@`: Границы для PM10.

## 5. Правила разработки

1. **Никакой логики в Go**: Запрещено формировать списки или выбирать иконки в коде. Используйте `evt*` флаги и условные операторы в JSON.
2. **Именование**: Всегда `camelCase`.
3. **HTML**: Используйте нативные теги `<b>`, `<i>`, `<code>`.
4. **Unicode**: Запрещено использование Unicode-экранирования (`\u003c`).
5. **Сортировка**: Ключи в JSON должны быть отсортированы тематически:
   - Мастер-шаблоны (`msg*`)
   - Текстовые компоненты (`txt*`)
   - События (`evt*`)
   - Кнопки (`btn*`)
   - Иконки (`ico*`)
