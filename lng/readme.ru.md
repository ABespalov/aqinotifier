# Система локализации AQI Notifier (v2.0)

Система основана на **рекурсивном блочном шаблонизаторе**. Основная логика формирования интерфейса вынесена из Go-кода в JSON-файлы.

---

## 1. Основной принцип: Блочная структура
Вместо сборки сообщений в коде, мы используем "мастер-шаблоны", которые ссылаются на другие блоки (плейсхолдеры).

**Пример (msgStatus):**
```json
"msgStatus": "@icoStatus@ <b>Последние значения</b>\n@txtDateTime@\n\n@txtAqi@\n\n@txtPm25@\n\n@txtDevice@"
```
При вызове `T("msgStatus")`, шаблонизатор автоматически найдет ключи `txtDateTime`, `txtAqi` и т.д. в этом же файле и подставит их.

---

## 2. Атомарные данные (из Go-кода)
Это первичные значения, передаваемые ботом. Они являются фундаментом для всех блоков.

| Плейсхолдер | Описание |
| :--- | :--- |
| @aqiVal@ | Индекс AQI (число). |
| @val25@ / @val10@ | Текущие значения PM (мкг/м³). |
| @diff25Percent@ | Изменение в % (например, +15.2). |
| @trend25Icon@ | Иконка тренда (icoTrendUp/Down). |
| @zone25Icon@ | Иконка зоны (icoGreenSq/YellowSq/RedSq). |
| @deviceId@ | ID устройства. |
| @deviceName@ | Имя устройства. |
| @date@ / @time@ | Объекты времени (требуют формата, напр. @date%02.01.2006@). |

---

## 3. Организация файлов (Сортировка)
Для удобства редактирования ключи в `ru.json` / `en.json` отсортированы **тематически**:
1. **Main Templates (msg...)**: Основные сообщения (Статус, Уведомление).
2. **Sub-templates (txt...)**: Блоки, из которых состоят сообщения (Дата, AQI, РМ).
3. **Buttons (btn...)**: Кнопки меню.
4. **Icons (ico...)**: Справочник иконок.
5. **System**: Единицы измерения, форматы, названия зон.

---

## 4. Правила оформления
1. **HTML-теги**: Используйте нативные `<b>`, `<i>`, `<code>`.
2. **Unicode**: Запрещено использовать Unicode-экранирование (типа `\u003cb\u003e`). Только чистый текст и теги.
3. **Иконки**: Все иконки начинаются с префикса `ico` (например, `@icoAqi@`).

---

## 5. Пример рекурсии
1. Код вызывает: `T("msgStatus", {"val25": 12.5, ...})`
2. `msgStatus` запрашивает `@txtPm25@`.
3. `txtPm25` берет `@val25@` из данных и `@unitPm@` из JSON.
4. Результат: **PM2.5: 12.50 мкг/м³**
