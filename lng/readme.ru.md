# Документация системы локализации AQI Notifier

Система построена на рекурсивном разрешении плейсхолдеров формата @ключ%формат@.

---

## 1. Атомарные плейсхолдеры (Данные из кода)
Это первичные значения, которые бот передает в систему шаблонов. Они ни от чего не зависят и являются «кирпичиками» для построения сообщений.

| Плейсхолдер | Тип | Описание |
| :--- | :--- | :--- |
| @val25@ / @val10@ | Float | Текущее значение PM2.5 / PM10. |
| @curr25@ / @prev25@ | Float | Текущее и предыдущее значения (для сравнений). |
| @diff25Percent@ | Float | Процент изменения (число). |
| @aqiVal@ | Float | Рассчитанный индекс AQI. |
| @deviceId@ | String | ID устройства (например, 12345). |
| @deviceName@ | String | Имя устройства. |
| @date@ | Time | Объект времени (дата). Требует формата. |
| @time@ | Time | Объект времени (время). Требует формата. |
| @unitPm@ | String | Единица измерения PM (мкг/м³). |
| @valT@ / @unitT@ | Float/Str | Температура и единица (°C/°F). |
| @valH@ | Float | Влажность (%). |
| @valP@ / @unitP@ | Float/Str | Давление и единица (мм.рт.ст/гПа). |
| @valDp@ | Float | Точка росы. |

---

## 2. Мета-холдеры (Структура JSON)
Мета-холдеры — это ключи в файлах локализации, которые используют атомарные данные для формирования сообщений.

### 2.1. Иконки
Любой ключ из ico.json доступен напрямую как @icoName@ (например, @icoStatus@, @icoAqi@).

### 2.2. Шаблоны сообщений (Пример msgStatus)
Основное сообщение статуса теперь собирается из независимых текстовых блоков (txt):

"msgStatus": "@icoStatus@ <b>Последние полученные значения</b>\n@txtDateTime@\n\n@txtAqi@\n\n@txtPm25@\n\n@txtPm10@\n\n@txtOtherUnits@\n\n@txtDevice@"

| Группа ключей (JSON) | Описание |
| :--- | :--- |
| msgStatus | Основной шаблон сообщения статуса. |
| txtDateTime | Блок даты и времени. |
| txtAqi | Блок индекса AQI. |
| txtPm25 / txtPm10 | Блоки показателей PM с динамикой и зонами. |
| txtOtherUnits | Блок метеорологических данных. |
| txtDevice | Блок идентификации устройства. |

---

## 3. Соответствие плейсхолдеров и иконок

| Плейсхолдер | Используемые иконки из ico.json |
| :--- | :--- |
| @icon@ | Круги уровней AQI: icoGreen, icoYellow, icoOrange, icoRed... |
| @zone25Icon@ | Квадраты зон PM: icoGreenSq, icoYellowSq, icoRedSq. |
| @trend25Icon@ | Тренды: icoTrendUp, icoTrendDown, icoTrendFlat. |

---

## 4. Форматирование дат и времени
Система поддерживает стандарт Go: %02.01.2006 (дата), %15:04:05 (время).
