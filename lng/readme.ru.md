# Система локализации AQI Notifier (v2.2)

Система локализации основана на мощном **рекурсивном блочном шаблонизаторе**, который позволяет выносить всю логику отображения (иконки, условия, склонения) из программного кода в JSON-файлы.

---

## 1. Синтаксис шаблонов

Базовый формат плейсхолдера: `@key%format@`

### 1.1. Модификаторы регистра (Case Formatters)
Используются для изменения регистра подставляемого значения:
- `%toUpper`: ПЕРЕВОДИТ В ВЕРХНИЙ РЕГИСТР
- `%toLower`: переводит в нижний регистр
- `%toTitle`: Делает Первую Букву Заглавной

**Пример:** `"Резкий @actionRise%toLower@"` (где `actionRise` = "Рост") -> "Резкий рост".

### 1.2. Числовое форматирование
Используется стандартный синтаксис Go `fmt.Printf`:
- `%.1f`: один знак после запятой (12.3)
- `%.2f`: два знака после запятой (12.34)
- `%d`: целое число

### 1.3. Форматирование даты и времени
Используется стандартный формат Go `2006-01-02 15:04:05`:
- `%02.01.2006`: ДД.ММ.ГГГГ (02.05.2024)
- `%15:04`: ЧЧ:ММ (14:30)

---

## 2. Условные конструкции (Logic)

Синтаксис: `@?condition%true_text%false_text@`

### 2.1. Операторы сравнения
- `==`, `eq`: Равно
- `!=`, `ne`: Не равно
- `>`, `gt`: Больше
- `<`, `lt`: Меньше
- `>=`, `le`: Больше или равно
- `isEmpty`: Проверка на пустую строку
- `isNotEmpty`: Проверка на наличие значения

### 2.2. Вложенные условия (Switch)
Если третья часть (else) начинается со знака `?`, она считается вложенным условием.
**Пример:** `@?isAlert%A%?isNorma%B%C@@` (Если Alert - A, иначе если Norma - B, иначе C).

---

## 3. Маппинг данных (Go -> JSON)

Ниже перечислены основные ключи, которые вызываются из кода, и данные, которые им передаются.

### 3.1. `msgStatus` (Статус устройства)
Вызывается при запросе текущих показателей.
**Передаваемые переменные:**
- `@date@`, `@time@`: Время измерения.
- `@aqiVal@`, `@aqiLevel@`: Значение и уровень AQI (1-7).
- `@aqiName@`: Локализованное название уровня (например, "Хорошо").
- `@aqiStandardFlag@`: Иконка флага стандарта (EU/US).
- `@val25@`, `@val10@`: Текущие значения PM.
- `@diff25Percent@`, `@diff10Percent@`: Изменение в процентах.
- `@trend25Icon@`, `@trend10Icon@`: Иконка тренда (вверх/вниз/ровно).
- `@zone25Icon@`, `@zone10Icon@`: Иконка текущей зоны (цветной квадрат).
- `@deviceName@`, `@deviceId@`: Информация об устройстве.
- `@valT@`, `@valH@`, `@valP@`: Температура, влажность, давление (если есть).

### 3.2. `msgAlertNotify` (Уведомление о событии)
Вызывается при срабатывании алертов.
**Дополнительные переменные (к списку выше):**
- `@isAlert@`: `true`, если это переход в опасную зону.
- `@isNorma@`: `true`, если это возвращение в норму.
- `@evt*@`: Флаги конкретных событий (например, `@evtVal10Yu@`, `@evtPm25Rise@`). 
  Если событие активно, переменная имеет значение `true`.

---

## 4. Правила разработки

1. **Никакой логики в коде**: Иконки, заголовки и составление списков алертов должны выполняться внутри JSON с помощью `@?condition%...%...@`.
2. **Имена ключей**: Всегда используйте `camelCase` для новых ключей.
3. **Unicode**: Запрещено использовать Unicode-экранирование (`\u003cb\u003e`). Используйте нативный HTML: `<b>`, `<i>` и т.д.
4. **Сортировка**: Сохраняйте тематическую группировку ключей. Мастер-шаблоны (`msg*`) всегда сверху.
