# Документация системы локализации AQI Notifier

Система построена на рекурсивном разрешении плейсхолдеров формата `@ключ%формат@`.

---

## 1. Атомарные плейсхолдеры (Данные из кода)
Это первичные значения, которые бот передает в систему шаблонов. Они ни от чего не зависят и являются «кирпичиками» для построения сообщений.

| Плейсхолдер | Тип | Описание |
| :--- | :--- | :--- |
| `@val@` | Float | Текущее значение датчика (число). |
| `@curr@` / `@prev@`| Float | Текущее и предыдущее значения (для сравнений). |
| `@diff@` | Float | Абсолютная разница между значениями. |
| `@diff_percent@`| Float | Процент изменения (число). |
| `@aqi_val@` | Float | Рассчитанный индекс AQI. |
| `@device_id@` | String | ID устройства (например, `12345`). |
| `@name@` | String | Пользовательское имя устройства или события. |
| `@date@` | Time | Объект времени (дата). Требует формата или ключа `format_date`. |
| `@time@` | Time | Объект времени (время). Требует формата или ключа `format_time`. |
| `@unit@` | String | Единица измерения (`°C`, `мкг/м³` и т.д.). |
| `@err@` | String | Текст системной ошибки. |
| `@count@` | Int | Число записей в истории. |
| `@status@` | String | Состояние (`enabled`/`disabled`). |
| `@icon@` | String | Основная иконка. Может принимать значения `IconPM25`, `IconPM10` или кружки уровней AQI (`IconGreen`, `IconRed` и т.д.). |
| `@zone_icon@` | String | Иконка зоны загрязнения. Принимает `IconGreenSq`, `IconYellowSq` или `IconRedSq`. |
| `@trend_icon@`| String | Иконка направления изменения. Принимает `IconTrendUp`, `IconTrendDown` или `IconTrendFlat`. |

**Специфичные строки (Pre-formatted):**
*   `@pcentStr@` — Готовая строка процента со знаком и тегами (напр. `<b>+15.2%</b>`).
*   `@newValStr@` — Готовая строка значения с юнитом (напр. `<b>25.4 мкг/м³</b>`).
*   `@aqi_standard_flag@` — Плейсхолдер флага (обычно `@flag_us@` или `@flag_eu@`).

---

## 2. Мета-холдеры (Структура JSON)
Мета-холдеры — это ключи в файлах локализации, которые используют атомарные данные для формирования сообщений.

### 2.1. Константы и Иконки (Базовые мета-холдеры)
Это простые строки или ссылки на иконки.
- **Иконки**: Любой ключ из `ico.json` доступен напрямую как `@IconName@`. 
- **@icon@ (плейсхолдер)**: Это динамический «контейнер». Код сам решает, какую именно иконку из `ico.json` в него подставить (например, `@IconGreen@` или `@IconRed@`).
- **Флаги**: `flag_us` (`@IconFlagUS@`), `flag_eu` (`@IconFlagEU@`).
- **Метки**: `label_pm25`, `label_dynamics`, `label_threshold`.

### 2.2. Шаблоны сообщений и их зависимости
Для каждого ключа в JSON ниже указаны атомарные плейсхолдеры, которые бот передает в этот шаблон.

| Группа ключей (JSON) | Доступные атомарные плейсхолдеры | Описание |
| :--- | :--- | :--- |
| `msg_status_header` | `@date@`, `@time@` | Шапка сообщения статуса (дата и время получения данных). |
| `msg_status_aqi` | `@icon@`, `@aqi_val@`, `@aqi_name@`, `@aqi_standard_flag@` | Строка общего индекса AQI в сообщении статуса. |
| `msg_status_pm` | `@icon@`, `@label@`, `@val@`, `@unit@`, `@zone_icon@` | Основная строка с текущими показателями PM2.5 или PM10. |
| `msg_status_diff` | `@trend_icon@`, `@diff_percent@`, `@prev@`, `@curr@` | Строка динамики изменений (процент, направление, старое/новое значения). |
| `msg_status_temp/hum/press`| `@label@`, `@val@`, `@unit@` | Строки метеорологических данных (температура, влажность, давление). |
| `alert_aqi_clean/full` | `@icon@`, `@standard@`, `@aqi_standard_flag@`, `@aqi_val@`, `@aqi_name@` | Текст пуш-уведомлений при изменении уровня AQI. |
| `alert_pm_rise/fall_to/in` | `@pm@`, `@zone@`, `@zone_acc@`, `@zone_pre@` | Текст пуш-уведомлений при переходе между зонами загрязнения PM. |
| `msg_history_footer` | `@count@`, `@device_id@` | Информационный подвал в сообщении с историей измерений. |
| `msg_reset_confirm_details`| `@pm25_g@`, `@pm25_y@`, `@pm25_dyn@`, `@pm10_g@...`, `@std_name@`, `@aqi_standard_flag@` | Полный список параметров, которые будут сброшены. |
| `msg_threshold_upd` | `@title@`, `@old@`, `@new@` | Сообщение об успешном изменении порога или настройки. |

## 3. Соответствие атомарных плейсхолдеров и иконок
В этой таблице указано, какие именно иконки из `ico.json` бот подставляет в те или иные атомарные плейсхолдеры в зависимости от логики.

| Плейсхолдер | Контекст (Ключ JSON) | Используемые иконки из `ico.json` |
| :--- | :--- | :--- |
| `@icon@` | `msg_status_aqi` | **Круги уровней**: `IconGreen`, `IconYellow`, `IconOrange`, `IconRed`, `IconPurple`, `IconMaroon`, `IconBlack`, `IconBlue`. |
| `@icon@` | `msg_status_pm` | **Тип частиц**: `IconPM25` или `IconPM10`. |
| `@zone_icon@` | `msg_status_pm`, `msg_threshold_title_fmt` | **Квадраты зон**: `IconGreenSq`, `IconYellowSq`, `IconRedSq`. |
| `@trend_icon@` | `msg_status_diff`, `msg_pm_alert_line` | **Тренды**: `IconTrendUp`, `IconTrendDown`, `IconTrendFlat`. |
| `@thresholdIcon@`| `msg_pm_alert_line` | **Квадраты зон**: `IconGreenSq`, `IconYellowSq`. |

## 4. Форматирование дат и времени

Система поддерживает стандартные спецификаторы Go для форматирования объектов `@date@` и `@time@`.

| Формат | Результат | Описание |
| :--- | :--- | :--- |
| `%02.01.2006` | `10.05.2026` | Дата: День.Месяц.Год |
| `%15:04:05` | `14:30:05` | Время: 24-часовой формат |
| `%03:04 PM` | `02:30 PM` | Время: 12-часовой формат |
| `%Mon, Jan 02` | `Sun, May 10` | День недели и краткая дата |

> [!NOTE]
> Если в шаблоне указано просто `@date@` (без `%`), бот попытается найти в JSON ключ `format_date` и применить его. Аналогично для `format_time` и `format_datetime`.

## 4. Рекурсивное разрешение (Пример)

Цепочка зависимости: **Атомарный -> Мета-холдер (JSON) -> Иконка (ico.json)**.

1. Код вызывает `T("btn_aqi_standard", {"std": "США", "aqi_standard_flag": "@flag_us@"})`.
2. В JSON: `"btn_aqi_standard": "Стандарт: @std@ @aqi_standard_flag@"`
3. Подстановка `@std@` -> `Стандарт: США @aqi_standard_flag@`
4. Подстановка `@aqi_standard_flag@` (значение передано кодом) -> `Стандарт: США @flag_us@`
5. В JSON: `"flag_us": "@IconFlagUS@"` -> `Стандарт: США @IconFlagUS@`
6. В `ico.json`: `"IconFlagUS": "🇺🇸"` -> **`Стандарт: США 🇺🇸`**
