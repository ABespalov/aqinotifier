# Модуль Dashboard (Визуальные дашборды)

Модуль `dashboard` предназначен для динамической отрисовки и сериализации показателей качества воздуха и графиков истории на экранах с высокой контрастностью. Он специально разработан для интеграции с панелями e-Ink/EPD (электронная бумага) или отображения динамических виджетов в форматах PNG/BMP.

---

## Возможности

- **Различные форматы**: Поддерживает логическую упаковку пикселей в бинарные буферы `epd_raw` (1 бит на пиксель, сначала старший бит MSB, последовательная склейка буферов), а также стандартные `png` и `bmp`.
- **Горячая перезагрузка (Hot Reload)**: Файлы разметки дашбордов (`.yaml` конфигурации) парсятся заново при каждом HTTP GET-запросе, что обеспечивает мгновенную обратную связь при редактировании.
- **Динамическая телеметрия и история**: Отрисовывает текущие показания датчиков, локализованные строки, рассчитывает производные метрики (например, точку росы, индексы AQI) и строит графики истории на основе усредненных интервалов.
- **Отказоустойчивый вывод ошибок**: В бинарный файл встроен моноширинный шрифт `Tamzen8x16r.ttf` для отображения критических ошибок или проблем с базой данных прямо на e-Ink экранах при сбое.
- **Список контроля доступа (ACL)**: Проверка подсетей CIDR и единичных IP-адресов клиентов прописывается прямо в YAML-файле разметки.

---

## Спецификация эндпоинтов

Дашборды регистрируются в главном файле конфигурации приложения в секции `dashboards` и доступны по протоколу HTTP/HTTPS GET.

**Параметры запроса:**
- `format` (опционально): `png`, `bmp` или `epd_raw`. Переопределяет формат вывода по умолчанию из YAML-файла.
- `device` / `device_id` (опционально): Идентификатор целевого датчика. Если не передан, используется первый доступный датчик в системе.

**Пример запроса:**
```bash
curl -o screen.png "http://localhost:28288/dashboard/eink75?format=png&device=LivingRoom"
```

## Схема конфигурации

Пример структуры файла разметки YAML (например, `eink_800x480.yaml`):

```yaml
# Размеры экрана и палитра
screen:
  width: 800                # Ширина в пикселях
  height: 480               # Высота в пикселях
  anti_aliasing: false      # Рекомендуется отключить для максимальной резкости на e-Ink
  palette:
    white: "#FFFFFF"
    black: "#000000"
    yellow: "#FFD500"
    red: "#FF0000"

lang: "ru"                  # Словарь локализации (например, res/ru.json)

defaults:
  fit_text: true            # Автоподбор размера шрифта под границы контейнера
  align:
    h: "center"             # Горизонтальное выравнивание: left, center, right
    v: "center"             # Вертикальное выравнивание: top, center, bottom

# Параметры вывода сериализации
output:
  format: "epd_raw"         # Формат по умолчанию: epd_raw, png, bmp
  background: "white"       # Цвет заливки холста
  mapping:                  # Маппинг цветов палитры в биты буферов EPD [Буфер1_Бит, Буфер2_Бит]
    black:  [0, 0]
    white:  [1, 0]
    yellow: [0, 1]
    red:    [1, 1]

# Список контроля доступа (ACL)
allowed:
  - "192.168.1.0/24"
  - "127.0.0.1"

# Определение шрифтов
fonts:
  aqi: { file: "fonts/PT-Root-UI_Bold.ttf", size: 100 }
  labels: { file: "fonts/PT-Root-UI_Medium.ttf", size: 20, hinting: "none" }

# Последовательность слоев отрисовки
layout:
  # Элемент статического или шаблонного текста
  - type: "text"
    position: { x: 20, y: 15 }
    size: { w: 180, h: 30 }
    font: { face: "labels", fg: "black" }
    template: "{date:02.01.2006} {time:15:04}" # Поддерживаются Go-форматы времени

  # Разделительная линия
  - type: "line"
    position: { x: 215, y: 20 }
    size: { w: 1, h: 440 }
    font: { fg: "black" }

  # Карточка показателя датчика
  - type: "value"
    source: "pm25.value"
    format: "%.0f"
    position: { x: 20, y: 250 }
    size: { w: 180, h: 55 }
    value:
      font: { face: "values", fg: "black" }
      align: { v: "bottom" }
      thresholds:
        - { condition: "pm25.us.zone.index >= 3", fg: "white" }
    label:
      font: { face: "labels", fg: "black" }
      align: { v: "top" }
    unit:
      font: { face: "units", fg: "black" }
      align: { p: "right", s: 3, v: "1/2" }
    border:
      thin: 2
      fg: "black"
      bg: "white"
      padding: 8
      affects: ["value", "unit"]
      thresholds:
        - { condition: "pm25.us.zone.index >= 3", bg: "red", fg: "red" }

  # График истории
  - type: "chart"
    position: { x: 260, y: 10 }
    size: { w: 520, h: 330 }
    source: "aqi.usa.value"
    style: "bar"
    duration: "24h"
    points: 48
    axis:
      y:
        show: false
        min_step: 50
        labels: { show: true, count: 7, font: "axis_y" }
        notches: { show: true, fg: "black", w: 8, h: 2 }
      x:
        show: true
        labels: { show: true, count: 7, format: "15:04", font: "axis_x" }
        notches: { show: true, fg: "black", w: 2, h: 8 }
    threshold_lines:
      - { condition: "aqi.usa.zone.index >= 3", fg: "red", w: 2, style: "dashed.2.14" }
    thresholds:
      - { condition: "aqi.usa.zone.index >= 3", bg: "red" }
```

## Механика упаковки битов EPD (epd_raw)

Когда выбран формат сериализации `epd_raw`:
1. Цвета пикселей на холсте соотносятся с наиболее близким цветом палитры, заданной в `screen.palette` (расчет идет по евклидовому расстоянию в RGB).
2. Правила в `output.mapping` определяют, какое значение бита (1 или 0) записывается в соответствующий буфер. Например, двухбуферный маппинг:
   - `black: [0, 0]` записывает `0` в Буфер 1 и `0` в Буфер 2.
   - `white: [1, 0]` записывает `1` в Буфер 1 и `0` в Буфер 2.
3. Биты упаковываются по схеме MSB-first: каждые 8 горизонтальных пикселей упаковываются в один байт.
4. Выходной массив байт представляет собой последовательную склейку: сначала идут байты Буфера 1, затем сразу байты Буфера 2.

## Высококонтрастная отрисовка ошибок

Если сервер сталкивается с ошибкой синтаксиса YAML-разметки, сбоем подключения к БД или паникой в рантайме:
- Генерируется изображение с пропорциями, заданными в разметке дашборда.
- Описание ошибки выводится в высококонтрастном черно-белом стиле.
- Для отрисовки используется встроенный моноширинный шрифт `Tamzen8x16r.ttf`, что гарантирует читаемость текста даже на низкокачественных экранах.
